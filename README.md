# Doctors Appointments Web App

A web application that allows patients to search for doctors, view availability, book and manage appointments. 

## Key Features
* **User Accounts:** Secure login and registration for users.
* **Doctor Search:** Browse available doctors and filter by specialty, location, or reviews.
* **Booking System:** Easily schedule and manage appointments.
* **Access Control:** Private dashboards restricted to logged-in users only.

## Tech Stack
* **Backend:** Java, Spring Boot, MySQL
* **Frontend:** React, JavaScript, CSS
* **Security:** Spring Security, JSON Web Tokens (JWT)
